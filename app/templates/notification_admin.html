Generate Web Push keys

Kaya will generate a public and private P-256 VAPID key pair. The private key will be encrypted using this installation's ENCRYPTION_KEY.

or

This removes the UI-managed key pair and revokes every browser subscription. In-app notifications and notification history are preserved.

Every user will need to register each browser again. Keys and in-app history are preserved.
